# 🌱 Aprende+

## 🎯 Objetivo

O Aprende+ é uma plataforma criada para ajudar as pessoas a cuidarem melhor da saúde mental por meio de micro-aprendizados (Microlearning) e micro-hábitos que podem ser incluídos na rotina.

A proposta é apresentar conteúdos de forma rápida e simples, permitindo que o usuário aprenda algo novo em poucos minutos e transforme esse conhecimento em pequenas ações no dia a dia. A ideia é mostrar que cuidar da mente não precisa ser complicado ou exigir grandes mudanças de uma vez.

## 💡 O que fazer no site

No Aprende+, você pode encontrar diferentes conteúdos e atividades voltados para o cuidado com a saúde mental.

A plataforma utiliza o conceito de Microlearning, apresentando informações de forma curta e objetiva, para que o usuário consiga aprender e aplicar o conteúdo sem precisar dedicar muito tempo.

Entre as opções disponíveis, você pode:

* Conhecer dicas para melhorar a qualidade do sono;
* Aprender técnicas de relaxamento;
* Entender melhor alguns sinais relacionados à saúde mental;
* Conhecer formas simples de lidar com momentos de ansiedade;
* Criar micro-hábitos para melhorar sua rotina;
* Fazer desafios rápidos que incentivam pequenas mudanças positivas no dia a dia;
* Tirar um tempo para meditar através da área de meditação.

A proposta é começar com pequenas ações, criando micro-hábitos de forma gradual e sem pressão.

## 💻 Tecnologias

O projeto foi desenvolvido utilizando:

* HTML5 — estrutura das páginas;
* CSS3 — estilização e aparência do site;
* JavaScript — funcionalidades e interações da página;
* Git e GitHub — controle de versão e armazenamento do projeto.
